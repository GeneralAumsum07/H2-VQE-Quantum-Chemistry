# H2-VQE-Quantum-Chemistry

Objective: Variational Quantum Eigensolver (VQE) workflow for the H molecule to compute ground-state energies at varying H–H distances and produce a potential energy curve.

Folders:
- 
otebooks/ — Jupyter notebooks.
- src/ — helper scripts.

Run:
1. Create & activate virtualenv: see requirements.txt  
2. Install dependencies: pip install -r requirements.txt  
3. Open the notebook: notebooks/H2_VQE_Notebook.ipynb
